# More Functions and Nested Loops

This project contains C functions that use conditions, loops, and nested loops.

## Task 0: isupper

The `_isupper` function checks if a character is uppercase.

- Returns 1 if the character is between A and Z.
- Returns 0 otherwise.

## Compilation

Compile with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`.
